# Наш ИИ-чат

Сайт для двоих (ПК и телефон) с общими и личными чатами, живой генерацией ИИ и отдельным чатом «Мы вдвоём». Поддерживаются Gemini и OpenAI: каждый вставляет свой API-ключ в настройках.

Как это работает:

- **Общие чаты**: видят оба, оба могут писать ИИ. Ответ идёт потоком, и второй видит, как он печатается.
- **Личные чаты**: видит только владелец (защищено правилами в БД).
- **Мы вдвоём**: живой чат между вами. Чтобы позвать ИИ, начни сообщение с `/ai`.
- **Ключи**: хранятся только в браузере (localStorage) и уходят напрямую к Google/OpenAI. В базу и на GitHub не попадают. Генерация идёт с ключа того, кто отправил сообщение.

## Настройка (один раз, ~10 минут)

### 1. Supabase
1. Зарегистрируйся на [supabase.com](https://supabase.com) и создай проект (бесплатный тариф подойдёт).
2. Открой **SQL Editor → New query**, вставь содержимое `schema.sql` и нажми **Run**.
3. **Authentication → Providers → Email**: отключи **Confirm email**, чтобы не ждать письма.
4. **Project Settings → API**: скопируй **Project URL** и **anon public key**.

### 2. Конфиг
Вставь URL и ключ в `config.js`. Anon-ключ публичный, его безопасно держать на GitHub.

### 3. GitHub Pages
1. Залей все файлы в репозиторий на GitHub.
2. **Settings → Pages → Deploy from a branch → main / root**.
3. Через минуту сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`. На телефоне можно добавить его на главный экран.

### 4. Закрой регистрацию
Когда вы оба зарегистрировались, в Supabase открой **Authentication → Sign In / Providers** и отключи **Allow new users to sign up**. Иначе любой, кто найдёт сайт, сможет создать аккаунт и увидеть общие чаты.

### 5. API-ключи
- Gemini: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- OpenAI: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

В приложении открой ⚙, вставь ключ и при желании поменяй название модели.

## Демо-режим
Если `config.js` пустой или в адресе есть `?demo`, сайт открывается в демо: без Supabase и регистрации, чаты хранятся в localStorage браузера, а ИИ без ключа отвечает заготовленным текстом. Кнопка «Сбросить» внизу списка чатов очищает демо-данные.

## Локальный запуск
Открой папку через любой статический сервер, например `python -m http.server 8000`, и зайди на `http://localhost:8000`.

## Заметки
- Сообщения в общих чатах лежат в вашей базе Supabase, а не у ИИ-провайдера. Запросы к ИИ уходят с вашего браузера.
- Если вкладка закрылась посреди генерации, у сообщения появится пометка «прервано».
